# 🌙 Hime VTuber Portfolio

A modern, responsive VTuber portfolio website built with **HTML, CSS and JavaScript**.


---

## 📖 Overview

Hime VTuber Portfolio là website giới thiệu nhân vật VTuber với giao diện hiện đại, hiệu ứng mượt mà và nhiều tính năng tương tác.

Website được thiết kế theo phong cách **anime / cozy / gaming**, phù hợp làm portfolio cá nhân hoặc landing page cho VTuber, Streamer hoặc Content Creator.

---
